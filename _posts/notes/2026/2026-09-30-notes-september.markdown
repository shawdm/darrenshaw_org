## Reading
1. Tim Harford's [Just how random is random?](https://www.ft.com/content/8dda77e2-626f-49b8-9f18-c68162c454fc) article
   on how humans can't do random. We'll pick heads more often. We'll pick two-digit numbers where the first digit is
   larger than the second more often. We're rubbish.
2. [Training AI to Paint with Code](https://surya.website/rling-qwen-to-paint-with-code). This is interesting. I thought
   it was going to be something that I've been playing with, using an AI to generate p5.js code to then generate an
   image (a two-step process that makes me feel like I'm contributing). But this is on another level. Surya Narreddi is
   using AI to generate p5.js code to generate an image which AI then uses to judge against a reference picture to
   refine the code it's generating. It is subtle, but generating the code to generate the image and then improving the
   code to make the image better feels more impressive than going directly to an image. And it provides scope for the
   programmer/artist to contribute.
3. [How to be less awkward](https://www.experimental-history.com/p/how-to-be-less-awkward). This will feel familiar to
   many computer nerds. It does to me. I admired many of the things about working with people in fashion. What I took as
   their confidence may have been an absolute lack of awkwardness.
4. [Search Quality Evaluation With LLMs: The Dataset Generator](https://sease.io/2026/07/search-quality-evaluation-with-llms-the-dataset-generator.html).
   Nerdy Solr stuff that I'm thinking about in the context of my day job. Lots more work-related stuff happening with Solr and
   re-ranking. [Apache Solr 10 – What Is New For Vector Search And LTR](https://sease.io/2026/03/apache-solr-10-what-is-new-for-vector-search-and-ltr.html), [New In Apache Solr 10: Improved Filtering In Vector Search With ACORN](https://sease.io/2026/03/new-in-apache-solr-10-improved-filtering-in-vector-search-with-acorn.html), [Late Interaction Comes To Solr](https://sease.io/2026/04/late-interaction-comes-to-solr-neural-reranking-introduction.html)
   and [Colbert Comes To Apache Solr](https://sease.io/2026/04/late-interaction-comes-to-solr-implementation-and-tutorial.html).
5. [Agentic Code Review](https://addyosmani.com/blog/agentic-code-review/). Code review is something I want to get better at. Everyone could. This made it more relevant and urgent.
